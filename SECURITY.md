# Security Policy

Do not report security vulnerabilities in a public issue.

Contact the maintainer directly via nrzGit (https://git.zweers.ch/nicorenezweers) instead. This keeps exploit details private while a fix is prepared.

Supported versions:

- `main`
- The latest published release

Include the affected version or commit, impact, reproduction steps or proof of concept, and any suggested mitigation. Do not include secrets that are still valid.
